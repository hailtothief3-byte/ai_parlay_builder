# AI Parlay Builder Buyer One-Sheet

## Positioning

AI Parlay Builder is a workflow and intelligence platform for:

- prop research
- ticket construction
- DFS handoff packaging
- results review
- post-result learning

It is not positioned as an automated wager-placement product.

## What makes it valuable

### 1. It is more than a board viewer

The product combines:

- live and demo board review
- ranked edge scanning
- sportsbook parlay construction
- DFS slip packaging
- ticket memory
- grading and bankroll workflow

### 2. It has an explainable intelligence layer

The product includes:

- smart pick scoring
- parlay leg audit
- recommendation logic
- review-driven feedback loops

That makes the workflow easier to trust, demo, and inherit.

### 3. It is packaging-ready

The app already includes:

- `Simple / Pro` view modes
- `Core / Pro / Owner` product packaging
- a buyer demo walkthrough
- setup, config, and deployment documentation

This lowers handoff friction for a buyer or collaborator.

## Best buyer profile

This asset is strongest for:

- a solo operator
- a small sports workflow studio
- a niche productivity-tool buyer
- someone who wants a working product surface rather than a raw codebase

## Current strengths

- production deployment path already in use
- live and demo workflows both supported
- demoable without full provider dependence
- saved tickets, grading, and bankroll workflow already present
- DFS handoff support already packaged

## Current risks

- still a Streamlit application, so UI/state regressions should be tested after major changes
- live provider workflows depend on valid API keys and usage limits
- some repo naming still reflects starter-era history and could be cleaned up later

## Cleanest buyer story

The strongest simple explanation is:

`AI Parlay Builder helps an operator scan markets, build tickets, review outcomes, and improve future decisions inside one workflow product.`
