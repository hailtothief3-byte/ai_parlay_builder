# AI Parlay Builder Screenshot Checklist

## Goal

Capture a small set of screenshots that make the product feel clear, real, and sellable without needing a long explanation.

The best screenshot set is usually 4 to 6 images.

## Before taking screenshots

1. launch the app locally
2. use `Reset To Buyer Demo Defaults`
3. confirm the page is in:
   - `Core`
   - `Simple`
   - `Light`
4. use the cleanest board state available

If live data looks messy, use a stable demo-backed posture instead.

## Screenshot 1: Overview hero

Capture:

- top controls
- hero section
- Overview title area

Why:

- this gives the buyer the first product impression

## Screenshot 2: Overview workflow story

Capture:

- `Today's Operating Mode`
- `Workflow Snapshot`
- `Suggested Next Steps`

Why:

- this shows the product is guided and not just a raw odds table

## Screenshot 3: Edge Scanner

Capture:

- ranked candidates
- filters
- clear edge or confidence columns

Why:

- this shows the ranking layer is real

## Screenshot 4: Parlay Lab

Capture:

- build controls
- ticket/slip structure
- stake planning or recommended workflow details

Why:

- this shows the product converts rankings into action

## Screenshot 5: Results & Grading

Capture:

- workflow status
- saved tickets or tracked picks
- ticket review section

Why:

- this shows memory and review depth

## Screenshot 6: Optional owner/handoff view

Capture only if it looks clean:

- `View Preferences`
- handoff docs readiness
- owner summary / documentation posture

Why:

- this helps a serious buyer understand that transfer is easier than usual

## What to avoid in screenshots

Avoid capturing:

- visible errors
- stale or broken live-provider warnings unless necessary
- code blocks or raw JSON unless you are showing technical depth on purpose
- overly crowded diagnostic screens for the first screenshot set
- unrelated browser clutter

## Best screenshot order for a sale package

1. Overview hero
2. Overview workflow story
3. Edge Scanner
4. Parlay Lab
5. Results & Grading
6. optional owner/handoff screenshot

## Naming suggestion

Use simple names like:

- `01_overview_hero.png`
- `02_workflow_story.png`
- `03_edge_scanner.png`
- `04_parlay_lab.png`
- `05_results_grading.png`
- `06_owner_handoff.png`
